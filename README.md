# 本地漫画阅读器

这是一个只读取本机漫画文件夹的离线阅读工具。它不会连接漫画网站，也不会加载广告、统计、远程字体或第三方脚本。

## 启动

双击 `启动漫画阅读器.command`。它会启动一个只监听 `127.0.0.1` 的临时本地服务并自动打开浏览器；终端窗口保持打开时服务持续运行，按 `Ctrl-C` 停止。

漫画目录位于本工具的上一级目录：

```text
30_Workbench/
├── 漫画/
└── 本地漫画阅读器/
```

刷新页面会重新读取实际文件夹内容。图片只从章节文件夹的根部读取，不会修改、复制或转码原始文件。

## 阅读操作

- 顶部左侧“本地漫画”或右侧“目录”：打开作品和章节抽屉。
- “长卷”：连续滚动阅读；“单页”：一页一页阅读。
- 明暗：切换阅读背景。
- 上一话、下一话：按当前的正篇/附录分组移动到实际存在的章节。
- 单页模式下使用左右方向键翻页；`PageUp` / `PageDown` 滚动长卷；`Esc` 关闭目录抽屉。
- 阅读位置、模式和主题保存在当前浏览器的本地存储中。

## 阅读顺序与目录规则

阅读器不再根据章节标题猜测顺序。当前旧资料的兼容映射保存在
`data/library_order.tsv`，每一行对应一个实际章节目录；修改清单后刷新页面即可生效。

新导入目录建议直接使用显式序号：

```text
作品名_S0001_正篇_第001话_标题_原始JPEG/
作品名_S0002_特别篇_特别篇01_标题_原始WebP/
作品名_A0001_附录_更新通知_原始JPEG/
```

- `S` 是剧情阅读顺序，`A` 是附录顺序；序号固定四位，只表示排列位置，不等于章节号。
- 需要插入中间章节时可用 `S0373.5`，阅读器使用精确十进制比较，不使用浮点近似。
- `序章`、`正篇`、`特别篇`共用一条剧情链；附录独立分组，不会进入剧情的上一话/下一话导航。
- 明确含“非剧情”“上架感言”“休刊”“通知”等标记的旧目录会进入附录。
- 没有显式序号且未出现在 TSV 的目录会标记为“待编序”，仍可从目录打开，但不会被猜测排序或加入上一话/下一话链。

只读检查当前顺序清单与实际目录是否一致：

```bash
python3 app.py --check-library
```

Git 仓库只保存阅读器代码、测试、规则文档和顺序清单，不保存漫画图片。
