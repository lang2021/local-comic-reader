# 本地漫画阅读器

这是一个只读取本机漫画文件夹的离线阅读工具。它不会连接漫画网站，也不会加载广告、统计、远程字体或第三方脚本。

## 启动

双击 `启动漫画阅读器.command`。它会启动一个只监听 `127.0.0.1` 的临时本地服务并自动打开浏览器；终端窗口保持打开时服务持续运行，按 `Ctrl-C` 停止。

漫画目录位于本工具的上一级目录：

```text
30_Workbench/
├── 漫画/
└── 本地漫画阅读器/
```

刷新页面会重新读取实际文件夹内容。图片只从章节文件夹的根部读取，不会修改、复制或转码原始文件。

## 阅读操作

- 顶部左侧“本地漫画”或右侧“目录”：打开作品和章节抽屉。
- “长卷”：连续滚动阅读；“单页”：一页一页阅读。
- 明暗：切换阅读背景。
- 上一话、下一话：按当前的正篇/附录分组移动到实际存在的章节。
- 单页模式下使用左右方向键翻页；`PageUp` / `PageDown` 滚动长卷；`Esc` 关闭目录抽屉。
- 阅读位置、模式和主题保存在当前浏览器的本地存储中。

## 目录规则

章节目录支持三位数字、第28.5话、`第N话`、序章和特别篇。明确含“非剧情”“上架感言”“休刊”“通知”等标记的目录放入附录，不会进入正篇的上一话/下一话链。
